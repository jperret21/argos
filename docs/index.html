Put your smart telescope to scientific work.

ARGOS is a desktop application for variable-star and exoplanet observing with smart telescopes. Telescope control over ASCOM Alpaca, ASTAP plate solving, linear 16-bit FITS, live differential photometry and AAVSO Extended export.

Workflow

Connect, identify, observe, review.

  1. 01Prepare

    Site, telescope profile and working folder. Resolve the target, check its altitude, and build the sequence: frame type, filter, exposure, gain, count, interval.

  2. 02Identify

    ASTAP solves the frame. Gaia DR3, VSX, SIMBAD, NASA hosts and VSP overlay it. Assign target, comparison and check roles.

  3. 03Observe

    Run the sequence with pause, resume and stop. One linear 16-bit FITS per frame. FWHM, HFD, sky background and the differential curve update live.

  4. 04Review

    Offline, with no telescope connected: quality trends, curves, FITS headers, and the source frame behind any measurement point.
