02

What changed

  • FOCRATIO corrected. Every FITS written before 0.4.1 carries f/3.2 instead of the S30 Pro's f/5.3 — an S50 aperture of 50.0 left in fits_writer.py. APTDIA is now written too. Check any frame you already hold.
  • Telescope profiles replace hard-coded optics. S30 Pro is the validated reference: 30 mm, f/5.3, IMX585, 3.74″/px. S30 and S50 are selectable but unvalidated — GRBG assumed, gain curve inherited. A driver mismatch warns at connect.
  • Startup: 26.1 s removed. run.sh ran xattr -dr com.apple.quarantine over 6 754 files on every launch, of which 0 were ever quarantined. Now conditional, with a splash showing real stage progress.
  • Field identification. Gaia DR3, AAVSO VSX, SIMBAD, NASA Exoplanet Archive hosts and AAVSO VSP, with a per-field query budget and local caches.
  • Photometry roles persist. Target, comparison and check selections are stored with the session, not just drawn as overlays.
  • Review works offline. Quality trends, curves, FITS headers and the source frame behind any point, with no telescope connected.
  • Packaging. .dmg and .deb built on native runners on every v* tag; each runs the full test suite and a headless smoke test of the frozen bundle before it is attached to the release.

03

Scope of this release

The live curve is a quick-look: uncalibrated, JD_UTC midpoints, no dark, flat or bias. Keep the raw FITS — the publishable measurement comes from Siril and star_var_script. Attended use only: there is no weather safety and no restart recovery.
